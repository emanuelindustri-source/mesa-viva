# Evidencia visual

Capturas de las versiones publicadas. Se conservan para auditoría y para que cualquier persona o IA pueda comprobar el estado real de la app sin reconstruirla.

| Versión | Carpeta | Contenido |
|---|---|---|
| v0.8.0 | [`v0.8.0/`](./v0.8.0/) | Cáscara Compose, catálogo, póker, Serpientes nativo, WebView y QR del APK |

Reglas:

1. No se borran las carpetas de versiones anteriores.
2. Las capturas se toman del APK o de la web publicada, no de maquetas.
3. Si una captura se reemplaza, se crea una versión nueva; no se sobrescribe la evidencia histórica.
