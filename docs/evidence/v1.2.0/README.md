El teléfono físico `23117RA68G` fue detectado por `adb`, pero MIUI bloqueó la instalación por USB: “Instalación bloqueada de Mesa Viva vía USB”. La instalación en el teléfono queda pendiente de habilitar **Instalar vía USB** en las opciones de desarrollador de MIUI. La verificación funcional se hizo en el emulador.
