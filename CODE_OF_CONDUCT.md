# Código de conducta

Mesa Viva es un espacio de juego. Tratamos a todas las personas con respeto, sin importar su país, idioma, identidad, nivel de experiencia o forma de jugar.

- No se toleran insultos, acoso, discriminación ni contenido sexual explícito.
- En salas y chat: nada de spam, suplantación, doxxing ni enlaces maliciosos.
- Las discusiones técnicas se centran en el código y en las ideas, no en las personas.
- Respeta las variantes culturales de cada juego y acredita las fuentes cuando corresponda.
- No se permite usar la app para apuestas con dinero real o actividades reguladas.

Los maintainers pueden moderar, cerrar hilos o expulsar a quien incumpla estas reglas. Para reportar un problema de conducta, escribe a **emanuel.industri@gmail.com** con confidencialidad.
